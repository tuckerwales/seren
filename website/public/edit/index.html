Seren Edit

A modern, fast and easy to use text and code editor for Android. It opens the files you choose, keeps them exactly as they were, and needs no permissions to do it.

  • No storage permission
  • No network permission

Features

Everything it does

Common actions are one tap away. Advanced options live in menus and settings, never removed.

Editing

  • Made for codeJetBrains Mono in the same 11 color schemes as Seren SSH, with Midnight by default.
  • Syntax highlightingKotlin, Java, JSON, XML, HTML, shell, Markdown, YAML and TOML. Anything else stays plain.
  • Comfortable on a phoneLine numbers, word wrap, pinch to zoom, and a text size setting with a live preview.
  • Extra keysTab, arrows, Home, End, undo, redo, brackets and symbols, right above the keyboard.
  • Indentation that behavesNew lines keep the indent of the line above, and Tab follows the file's own style.
  • Find and replaceCtrl+F and Ctrl+H, with match case. Hardware shortcuts cover save, undo and redo too.

Files

  • Open what you chooseCreate a file anywhere, open any file, or add whole folders to browse from the Files tab.
  • Open with Seren EditFrom other apps for text, JSON, XML, YAML, TOML and shell files.
  • Recent filesEach with its own color, so the ones you use most are easy to spot.
  • Leaves your files as they wereKeeps each file's encoding (UTF-8, UTF-16, Latin-1, with or without a byte order mark) and its line endings.
  • Careful with big and binary filesWarns over 2 MB, refuses over 16 MB, and turns away binary files with a clear reason instead of corrupting them.
  • Never loses your workAsks before discarding unsaved changes.

Privacy

It only sees what you open

Seren Edit uses the Android file picker instead of storage permissions, so it can reach only the files and folders you choose. With no network permission, it has no way to send them anywhere.

Permissions

  • Storage (not used)Not needed. Android hands Seren Edit only the files and folders you pick.
  • Network (not used)Not requested, so nothing you write can leave the device.
  • BiometricsOnly used if you turn on app lock.

Better together

Works with the other Seren apps

Seren Edit works fine on its own. Install the others and the right actions appear.

  • Open in Seren Edit

    Any text file in Seren Files, dotfiles and config files included, opens in Seren Edit and saves straight back.

Each action appears only when the other app is installed. The apps hand each other files through ordinary Android intents, never secrets.
