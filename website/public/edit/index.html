Seren Edit

A modern, fast and easy to use text and code editor for Android. It has no storage or network permission, so it can only open files you pick.

  • Early days
  • Android 8.0 and newer

Features

Editing

  • Font and colorsJetBrains Mono, with the same 11 color schemes as Seren SSH. Midnight is the default.
  • Syntax highlightingKotlin, Java, JSON, XML, HTML, shell, Markdown, YAML and TOML. Other files are shown in one color.
  • ViewLine numbers, word wrap, pinch to zoom, and a text size setting with a preview.
  • Extra keysA row above the keyboard with Tab, arrows, Home, End, undo, redo, brackets and symbols.
  • IndentationNew lines keep the indent of the line above. Tab inserts tabs or spaces to match the file.
  • Find and replaceCtrl+F and Ctrl+H, with a match case option. Keyboard shortcuts also work for save, undo and redo.

Files

  • Opening filesCreate or open a file anywhere, or add a folder to browse it from the Files tab.
  • Open withOther apps can open text, JSON, XML, YAML, TOML and shell files in Seren Edit.
  • Recent filesA list of files you've opened, each with a color you can set.
  • Encodings and line endingsUTF-8, UTF-16 and Latin-1, with or without a byte order mark, and LF, CRLF or CR line endings are kept as they were.
  • Large and binary filesFiles over 2 MB get a warning. Files over 16 MB and binary files aren't opened, and the app says why.
  • Unsaved changesThe app asks before discarding them.

Permissions

Seren Edit uses the Android file picker instead of a storage permission, so it can only see files and folders you choose.

  • Storage (not used)Not requested. Files come through the system file picker.
  • Network (not used)Not requested.
  • BiometricsOnly used if you turn on app lock.

With other Seren apps

  • Open in Seren Edit

    Open text files, including dotfiles, from Seren Files in Seren Edit. Saving writes back to the original file.

These actions only show up when the other app is installed. The apps pass files to each other through Android intents, not passwords or keys.
