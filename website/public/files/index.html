Seren Files

A modern, fast and easy to use file manager for Android. It has no network permission, and deleted files stay in a trash for 30 days.

Features

Browsing

  • StorageInternal storage, SD cards and USB drives, each with its free space.
  • Shortcuts and bookmarksDownloads, Documents, Camera, Pictures, Music and Movies on the Browse tab, plus bookmarks for any folder.
  • SortingBy name, date, size or type, ascending or descending. Numbers sort naturally, so photo 2 comes before photo 10.
  • List or gridPhotos and videos get thumbnails in both.
  • CategoriesAll images, videos, audio, documents, archives or apps on the device in one list, and Large files for anything over 25 MB.
  • Recent and searchRecent shows files changed in the last 30 days. Search looks through a folder and its subfolders.

Working with files

  • Name clashesWhen a name is taken, choose Replace (folders merge), Keep both or Skip.
  • Copy and moveCopies show progress, can be cancelled, keep dates, and don't leave partial files behind. Moves on the same storage are renames.
  • ArchivesCompress to zip. Extract zip, 7z (password protected too), tar, tar.gz, tar.xz, tar.bz2, gz, xz and bz2.
  • Free spaceA copy that won't fit is refused before it starts, with how much space it needs.
  • Background jobsLong copies continue if you leave the app, with a progress notification.
  • DetailsType, size (including folder totals), date, location, and SHA-256 on request.

Trash

  • UndoDeleted items move to a trash folder on the same storage, so deleting is instant and can be undone.
  • RestoreItems go back to where they were. Missing folders are recreated and nothing is overwritten.
  • EmptyingItems are deleted after 30 days, or sooner with Empty trash. The trash can also be turned off.

With other apps

  • Save to Seren FilesAppears in the share sheet. Pick a folder and tap Save here. Shared text is saved as a .txt file.
  • File pickerOther apps can use Seren Files to pick attachments. They get read only access to the files you choose.
  • Home screen shortcutsPin a folder to the home screen.

Permissions

A file manager needs to see your files, so Seren Files asks for all files access. It doesn't request network access.

  • Network (not used)Not requested.
  • All files accessAsked for when you tap Allow access, after an explanation of why it's needed.
  • NotificationsOn Android 13 and newer, asked for the first time a long copy starts, to show its progress.
  • BiometricsOnly used if you turn on app lock.

With other Seren apps

  • Open in Seren Edit

    Open text files, including dotfiles, from Seren Files in Seren Edit. Saving writes back to the original file.

  • Upload with Seren SSH

    Send files from Seren Files to a server over SFTP.

  • Import into Seren SSH

    Private keys (id_ed25519, .pem, .ppk) open in Seren SSH's Import key screen.

  • Show in Seren Files

    After an SFTP download, open the folder it was saved to.

These actions only show up when the other app is installed. The apps pass files to each other through Android intents, not passwords or keys.
