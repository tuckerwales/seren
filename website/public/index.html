Free Android apps with no ads or tracking

Seren is four Android apps: an SSH client, a text editor, an authenticator and a file manager. They're open source, and none of them need an account.

What every app has in common

Free, always

There's no paid version and nothing to unlock. The apps don't ask for donations.

No ads, no tracking

The apps contain no ad, analytics or crash reporting libraries. Network access is only requested by apps that need it.

Open source

The source is on GitHub under the Apache License 2.0.

Data stays on your phone

Passwords and keys are encrypted with the Android Keystore and kept out of cloud backup. Everything can be exported.

The apps

They share a design and the same terms for things, so once you know one, the others work the way you'd expect.

Using them together

Each app works on its own. If you have more than one installed, they add actions for each other.

  • Open in Seren Edit

    Open text files, including dotfiles, from Seren Files in Seren Edit. Saving writes back to the original file.

  • Upload with Seren SSH

    Send files from Seren Files to a server over SFTP.

  • Import into Seren SSH

    Private keys (id_ed25519, .pem, .ppk) open in Seren SSH's Import key screen.

  • Show in Seren Files

    After an SFTP download, open the folder it was saved to.

  • Shared backup encryption

    Password protected backups from Seren SSH and Seren Auth use the same format: scrypt and AES-256-GCM.

These actions only show up when the other app is installed. The apps pass files to each other through Android intents, not passwords or keys.

Source code

All four apps are in one repository, along with Seren Core, the library they share for the theme, components and encryption.

  • Apache License 2.0Third party licenses are listed in each app's README and About dialog.
  • Continuous integrationGitHub Actions builds and tests every push and uploads debug and release APKs.
  • One signing keyThe apps are signed with the same key. The actions between them need a permission that only apps with that key hold.

Questions

What does Seren mean?

It's Welsh for star, pronounced SEH-ren (the e as in set). The apps are made in Wales.

How do I install the apps?

They aren’t on the Play Store yet. APKs are built for every commit and can be downloaded from GitHub Actions, or you can build them from source.

Get all the apps from the same place. They're signed with the same key, and Android won’t install one alongside apps signed with a different key.

Does it cost anything?

No. There's no paid version, subscription or in-app purchase.

Do I need an account?

No. There's no sign up and no server. Each app can export its data to a file in a documented format.

Which phones are supported?

Android 8.0 and newer. On Android 12 and newer the apps can use colors from your wallpaper.
