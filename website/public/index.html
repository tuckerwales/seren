Everyday apps that don’t track you

Seren is a small suite of Android apps: an SSH client, a text editor, an authenticator and a file manager. Free and open source. No ads, no tracking, no account.

Four promises

Good software shouldn’t cost you your privacy

Every Seren app makes the same four promises. They are the whole point, and everything else is there to keep them.

Free, always

No paid tier, no pro unlock, no nag screens, and no donation prompts inside the apps.

No ads, no tracking

No ad SDKs, no analytics, no crash reporters, and no network calls you didn't ask for.

Open source

Every line is public under the Apache License 2.0, and builds with a single command.

Yours, on your device

Data stays local, secrets use a hardware-backed key, and export is always there.

Better together

Each app works alone, and knows the others

Install two and they start to help each other. No setup, no accounts, just the right action in the right place.

  • Open in Seren Edit

    Any text file in Seren Files, dotfiles and config files included, opens in Seren Edit and saves straight back.

  • Upload with Seren SSH

    Send one file or several to a server over SFTP. Pick the server, pick the folder, done.

  • Import into Seren SSH

    Private keys like id_ed25519, .pem and .ppk go straight to Import key, filled in.

  • Show in Seren Files

    After an SFTP download, jump to the folder it was saved in.

  • One backup lock

    Seren SSH and Seren Auth protect backups with the same scrypt and AES-256-GCM encryption.

Each action appears only when the other app is installed. The apps hand each other files through ordinary Android intents, never secrets.

Questions

Good to know

What does Seren mean?

Seren is Welsh for star, said SEH-ren, with a short “e” as in “set”. A star is a small, steady light that anyone can use to find their way and nobody owns, which is what these apps try to be. It is also a nod to where they are made.

How do I install the apps?

Seren isn’t on the Play Store yet. Every push is built and tested on GitHub, and the APKs are attached to each run on GitHub Actions. You can also build them yourself with one command.

Install every Seren app from the same place. They share a signing key, and Android won’t mix apps signed with different keys.

Why is it free?

Because everyone deserves good tools that don’t track them. There is no paid tier, no pro unlock, and there never will be. The apps are made carefully, to the standard you would expect from something you paid for.

Do I need an account?

No. There is no sign up, no sync server and no cloud. Your data stays on your device, and every app can export it in a plain, documented format, so you are never locked in.

Which phones are supported?

Android 8.0 or newer. The apps follow Material 3, with light and dark themes and colors from your wallpaper on Android 12 and newer.
