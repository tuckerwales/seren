Seren SSH

A modern, fast and easy to use SSH client for Android.

Part of Seren: free, carefully made, and built so you aren’t the product.

Custom xterm-compatible terminal, public key and password auth (including 2FA prompts), jump hosts, port forwarding, SFTP, and multiple sessions kept alive in the background. Passwords and private keys are encrypted with the Android Keystore.

Features

From the Seren SSH README. Nothing invented.

Terminal

  • Custom xterm-compatible emulator with 256 colors and truecolor, bold/italic/underline, mouse reporting, bracketed paste, and OSC 52 clipboard
  • Wide-character (CJK, emoji) handling, scrollback with reflow, pinch to zoom, and long-press selection
  • Extra keys row (Esc, Tab, sticky Ctrl/Alt, arrows, F1–F12) and hardware keyboard support
  • 11 color schemes (Midnight, Dracula, Catppuccin, Nord, and more), with per-host override

SSH

  • Password, keyboard-interactive (2FA) and public key authentication
  • Ed25519, ECDSA and RSA keys: generate on device or import OpenSSH, PEM and PuTTY keys
  • Trust-on-first-use host key verification with SHA-256 fingerprints
  • Jump hosts (ProxyJump), local/remote/dynamic port forwarding, and an optional in-app SSH agent
  • SFTP file browser: browse, upload, download, rename, delete, create folders, change permissions
  • Multiple concurrent sessions kept alive by a foreground service, with keep-alives and one-tap reconnect

Privacy

  • Passwords and private keys encrypted with AES-256-GCM via the Android Keystore
  • Optional app lock with biometrics or the device screen lock
  • No cloud backup of secrets; export hosts as JSON, or a password-encrypted full backup

With other Seren apps

  • “Import into Seren SSH” from a private key in Seren Files
  • “Upload with Seren SSH” from Seren Files to pick a server
  • After an SFTP download, “Show in Seren Files” opens the folder it was saved in
