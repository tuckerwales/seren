Seren SSH

A modern, fast and easy to use SSH client for Android. Passwords and private keys are encrypted with the Android Keystore, and sessions keep running in the background.

  • Ready for daily use
  • Android 8.0 and newer

Features

Terminal

  • xterm compatible256 colors and truecolor, bold, italic and underline, mouse reporting, bracketed paste and the alternate screen. tmux, vim and htop display correctly.
  • UnicodeWide characters (CJK, emoji) and combining characters are handled correctly. Box drawing is drawn by the app, so lines join up.
  • TouchPinch to zoom, fling to scroll back, long press to select. Scrollback reflows when the screen size changes.
  • Extra keysEsc, Tab, sticky Ctrl and Alt, arrows that repeat, Home, End, PgUp, PgDn and F1 to F12. Hardware keyboards work too.
  • Color schemes11 of them, including Midnight, Dracula, Catppuccin, Nord, Gruvbox and Solarized. Each host can use its own.

Connecting

  • AuthenticationPassword, keyboard-interactive (for 2FA prompts) and public key.
  • KeysGenerate Ed25519, ECDSA and RSA keys on the phone, or import OpenSSH, PEM and PuTTY keys.
  • Host key checksYou confirm a host's SHA256 fingerprint the first time you connect, and get a warning if it changes.
  • Jump hosts and forwardingProxyJump chains, plus local, remote and dynamic (SOCKS4, 4a and 5) port forwarding.
  • SSH agentOptional, with agent forwarding set per host. It requires app lock and is cleared when the app locks.

Sessions and files

  • Background sessionsRun several sessions at once. A foreground service keeps them connected, and reconnecting is one tap.
  • SFTP browserBrowse, upload, download, rename, delete, create folders and change permissions.
  • Upload from other appsShare files to Seren SSH, pick a session or saved host and a folder, and they upload one after another.
  • Quick connectType user@host:port, or open an ssh:// link. Each host can have a startup command, such as tmux new -A -s main.

Data

  • Hosts and snippetsHosts have groups, colors and search. Snippets are saved commands you can send to any session.
  • EncryptionPasswords and private keys are encrypted with an AES-256-GCM key in the Android Keystore, and left out of cloud backup.
  • BackupsExport hosts and snippets as JSON, or export everything, including keys, in a file encrypted with a password.
  • App lockUses biometrics or the screen lock. While it's on, the app's contents are hidden in recent apps.

Permissions

Seren SSH only connects to hosts you tell it to. It has no analytics or crash reporting.

  • NetworkUsed to connect to your hosts.
  • NotificationsA notification for open sessions, which lets them run in the background.
  • BiometricsOnly used if you turn on app lock.

With other Seren apps

  • Upload with Seren SSH

    Send files from Seren Files to a server over SFTP.

  • Import into Seren SSH

    Private keys (id_ed25519, .pem, .ppk) open in Seren SSH's Import key screen.

  • Show in Seren Files

    After an SFTP download, open the folder it was saved to.

  • Shared backup encryption

    Password protected backups from Seren SSH and Seren Auth use the same format: scrypt and AES-256-GCM.

These actions only show up when the other app is installed. The apps pass files to each other through Android intents, not passwords or keys.
